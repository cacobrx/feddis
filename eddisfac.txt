Consideraciones generales
Tener un registro de auditoría con todas las tareas que se realizan
Usar una base de datos mysql
Usar opcion de claro y oscuro para la interface
Login
Hacer el login con documento y clave eddis. Si no tiene documento en el sistema eddis, loguearse con los datos de studio beauty
Al acceder con ese documento, tiene acceso a los distintos centros de eddis y sb directamente
El usuario tiene que estar autorizado a poner facturar

Esto lo hace por medio de una api para obtener la validación del usuario

Pagos
Mostramos los pagos en el rango de fecha por el centro seleccionado. Poder filtrar desde nro de cuota, pagos de central o propios, 
Desde este módulo podemos seleccionar en el checkbox correspondiente, los pagos para pasarlos a facturas, indicando el importe que vamos sumando para no pasarnos del total autorizado. 
Para obtener los pagos vamos a usar una api al sistema de gestion eddis
Comprobantes Fiscales
Son los comprobantes que se generan a partir de los pagos del módulo anterior. Inicialmente estos registros no van a estar autorizados por arca. Poder seleccionar los registró con su checkbox correspondiente para autorizar en ARCA usando la api correspondiente
CUIT
Si estoy logueado como staff, tendría que ser un crud de datos de cuit (razón social, nombre fantasía, domicilio, ciudad, condición iva, centro, alícuota, punto de venta, fecha inicio de actividades, vencimiento certificado ARCA, Tope facturación, Importar cuota 99, Modo Prueba)

Si estoy logueado como no staff, veo para actualizar: Nombre Fantasía, Razón Social, domicilio, ciudad, cuit, condición IVA, Alicuota, punto de venta, inicio actividades, vencimiento certificado, tope facturación, Modo prueba
Consulta ARCA
Permite consultar los comprobantes en ARCA, ingresando Tipo de Comprobante según la condición de iva: monotributo y exento → Factura C / Nota de Crédito C), Responsable Inscripto → Factura A / Factura B / Nota de Crédito A / Nota de Crédito B
Datos Terceros
Permite indicar que cuando un alumno necesita hacer una factura  a una empresa, se completan los datos de Documento, Razón Social, Dirección, Ciudad, Cuit, Condición IVA. De esa forma, cuando se factura a un alumno ingresado aquí, se lo hace a la empresa indicada
